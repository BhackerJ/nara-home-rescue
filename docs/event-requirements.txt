What to build

The Actor world is hot right now. Come build your own Software Factory, long-running agent, multiplayer AI system or something super creative you've been itching to try out.

Projects should ideally use either Durable actors, or Agent Relay (bonus points if you use both at the same time).

Rules

All code must be created at the hackathon.

Thinking of ideas before the hackathon is fine.

Judging

We will be using devpost! We recommend setting up your account ahead of time.

The top entries will demo live at the end of the event, and judges will select winners from those demos.

Judges are looking for either very well-executed products or incredibly creative use cases using Durable Actors and Agent Relay. Again, bonus points if you can do both!
